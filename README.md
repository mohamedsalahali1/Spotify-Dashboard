# 🎧 Spotify Dashboard - Power BI

## 📌 Project Overview
This project is an interactive **Power BI dashboard** built to analyze Spotify data.  
It provides insights into songs, artists, and albums, focusing on **popularity, duration, release trends, and explicit vs. non-explicit content**.  

The goal of this project is to demonstrate **data modeling, DAX calculations, Power Query transformations, and advanced Power BI design**.

---

## 📊 Dashboard Pages

### 🔹 1. Overview Page
- Total Songs, Distinct Artists, Avg Popularity, Avg Duration.  
- Explicit vs. Non-Explicit songs distribution.  
- Songs by Year & Album Type.  
- Popularity trends by Month & Album.  

### 🔹 2. Artist Page
- Popularity insights at the artist level.  
- Distinct tracks per artist.  
- Popularity performance across songs.  

### 🔹 3. Songs Page
- Detailed analysis of songs (popularity, position, duration).  
- Explicit vs. Non-Explicit classification.  
- Interactive visuals highlighting top songs.  

---

## 🛠 Tools & Technologies
- **Power BI** (Data Modeling, DAX, Power Query, Dashboard Design)  
- **DAX** for calculations and KPIs  
- **Power Query (M Language)** for data transformation  
- **Spotify Dataset** (songs, artists, albums metadata)
